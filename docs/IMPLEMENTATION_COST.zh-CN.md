## 已落地修改

1. **补齐工具交接。** `platform.service.context` 原先已定义 case schema，但 模型调用装配没有将它传给分析/实现/交付模型。现在 `tool_runtime.platform_execution` 包含实际构建、格式化、运行命令、case 字段/动作/例子以及当前镜像、固件/QEMU 参数。控制器能力不再只存在于源码里。
2. **提供格式化基础设施。** `environment platform format RUN --package NAME [--package NAME] [--write]` 使用同一验证镜像、缓存和项目锁。默认检查，显式 `--write` 才修改源码；不默认格式化整个内核。保留命令、前后源码身份和日志。格式化不是构建通过，更不是驱动通过；修改后旧构建身份失效。先格式化再构建/运行，减少末尾格式修改引起的重复验证。
3. **按行为提供提示。** 新的 `behavior-job.md` 只用于当前行为或初次规划回合。不再次推送上游 Skill/workflow 路由入口；源码语义、目标安全和测试等技术参考仍按需可读。规划、one-behavior 调度、持续会话、continue/done、局部适配和最终验收边界未变。全部行为完成后恢复完整交付模板；模板和技术参考仍绑定策略身份。
4. **缩小工具反馈。** 开发检查成功时只返回状态、收据和日志位置；失败保留摘要和有界尾部。运行检查展示至多三个 observation 入口，其余在收据内。完整命令、输入身份、全部日志仍留存，执行和验收规则未变。不缓存任意构建脚本结果，不忽略源码变化，不把多次部分检查拼成全测 PASS。
5. **取消检索配额。** 新分析使用显式 `mode=focused`，只记录实际需要的检索；不再强制七个主题都查一次和论证“不适用”。零检索明确记为 `NO_RETRIEVAL_REQUESTED`，不是语义覆盖或检索成功。已提供的条目仍逐项回放 query、校验 chunk 原文/行号/报告身份。旧无 mode 的规格保留七主题校验。已知路径可直接读冻结版本定义；仅搜索未命中不触发 evidence_closure 返工。生成的 KB Skill 同步为按信息缺口使用，防止另一份提示重新要求固定检索。

提示词独立存放于 `src/driver_port_factory/data/prompt-packs/default/`，便于逐份审阅。`behavior-job.md` 定义本回合边界，`delivery-task.md` 定义实现责任，`behavior-execution.md` 定义工具与证据使用；最终模板为 `job.md`。KB 使用规则在 `data/project-kb-skill.md`。

## 验证和剩余限制

回归验证真实控制器的提示注入、模板身份、continue 不接受交付；使用合成执行器验证 CLI 格式化、固定镜像、源码改变使旧构建失效；检查聚焦检索仍拒绝伪造/失效证据，零检索不能伪装为已检索；检查精简反馈仍保留真实错误和原始收据。它们全部离线，不代表真实驱动正确性或真实费用降低。

完整测试与 Ruff 输出保存在 [审计目录](audits/implementation-cost-2026-10-03/)。仓库原有 lint/format 债务单独记录，不对无关文件做批量改写。验证完成后的结果见该目录 `validation.md`。

## 知识库使用的观察边界

对实验 04 的原始命令核查：分析阶段实际调用了 knowledge search/show/packet/check-probes；实现阶段没有观察到 knowledge search/rag/shared-search 调用，只有读取 Skill 文件以及直接读分析报告和源码。读取 `knowledge-guided-driver-port/...` 的文件名不能误计为知识库查询。没有查询也不等于没有复用分析结果，但不足以支持“工作模型主动复用了跨驱动经验”的结论。

该轮共享快照只有 121 条 ORIGINAL 和 1 条 EXPERIENCE；唯一经验是源 trylock 提前返回到目标 try_lock 的适配，未包含 BAR 分配、组件链接等经验。不能把前面跑过实验等同于这些经验已经入库。当前捕获/发布接口需要显式运行，不会从任意未完成实验自动生成可信经验。

新逐行为提示给出按具体问题调用 shared-search / 项目 RAG 的完整参数，并明确优先使用已提供的分析定位；已有证据足够时跳过检索。下一轮保持同一共享快照以区分提示/工具修复效果，不导入旧候选驱动或旧 PASS。审计分别记录实际查询命令、返回的经验/原文、是否在实现决定中引用，以及继续读取了哪些源码。查询次数本身既不是质量也不是降本指标；无法从日志确认的采用情况如实记为未知。
