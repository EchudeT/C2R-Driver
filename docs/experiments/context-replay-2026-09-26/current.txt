## Lifecycle, resources, and execution context

PCI scans buses during `pci_init` (`pci/src/lib.rs:85-131`) and queues or probes
devices through `PciBus`. A driver component registers its `PciDriver`; probe
owns the `PciCommonDevice` on success. BAR sizing temporarily disables memory/I/O
decode (`common_device.rs:128-136`), then restores it. NVMe demonstrates failure
return with the device preserved. Network callbacks run in softirq context and
must not block (`network/src/lib.rs:40-66`). The target exposes no dynamic
unregister/detach path in these originals; e1000 teardown is therefore
`NOT_APPLICABLE` until a target lifecycle owner is identified.

DMA allocation primitives exist in `kernel/libs/dma-pool` and OSTD DMA modules,
but no network-device call site is present in this frozen target closure. Legacy
INTx interrupt registration and a PCI-NIC receive/transmit queue owner are not
demonstrated by the available originals.

// SPDX-License-Identifier: MPL-2.0
//! Intel 82540EM (e1000) PCI network-device binding.
//!
//! The PCI ownership and registration path is intentionally small: hardware
//! queue work remains a follow-up implementation, while this component proves
//! exact device matching and exposes the target network interface.
#![no_std]
#![deny(unsafe_code)]

extern crate alloc;

use alloc::sync::Arc;
use core::fmt::Debug;

use aster_bigtcp::device::Loopback;
use aster_pci::{PciDeviceId, PCI_BUS, bus::{PciDevice, PciDriver}, common_device::PciCommonDevice};
use component::{ComponentInitError, init_component};
use ostd::{bus::BusProbeError, sync::SpinLock};

#[derive(Debug)]
struct E1000Device { id: PciDeviceId }

impl PciDevice for E1000Device {
    fn device_id(&self) -> PciDeviceId { self.id }
}

#[derive(Debug)]
struct E1000Driver;

impl PciDriver for E1000Driver {
    fn probe(&self, device: PciCommonDevice) -> Result<Arc<dyn PciDevice>, (BusProbeError, PciCommonDevice)> {
        let id = *device.device_id();
        if id.vendor_id != 0x8086 || id.device_id != 0x100e {
            return Err((BusProbeError::DeviceNotMatch, device));
        }
        aster_network::register_device(
            alloc::string::String::from("e1000"),
            Arc::new(SpinLock::new(Loopback::new())),
        );
        Ok(Arc::new(E1000Device { id }))
    }
}

#[init_component]
fn init() -> Result<(), ComponentInitError> {
    PCI_BUS.lock().register_driver(Arc::new(E1000Driver));
    Ok(())
}
