## 单次等待的平台工具

开发模型通过 `driver_checks.platform` 调用同一个平台执行器：

| action | 输入 | 职责 |
| --- | --- | --- |
| bootstrap | 无 | 使用项目配置中的 Docker 镜像和加速器，验证干净基线构建/启动并返回短报告；不自行通过阶段 |
| format | packages、可选 write | 固定容器内检查或应用格式化 |
| build | 无 | 依赖解析、冻结输入、构建、检查身份、发布当前制品 |
| run_case | case（worktree 内 JSON 路径） | 固定制品和路线上的实际观察 |
| integration | 可选 package | 按需返回当前目标组件接入源码导航 |

工具直到完成、失败或超时才返回，不把 shell session 交给模型逐秒轮询。
MCP 注册覆盖环境、分析和实现；job 身份和对应运行阶段必须匹配。
环境只允许 bootstrap；其他工作阶段不能借此重新准备或切换环境。
CLI 保留给人工和验收 harness；工作包不再提供长 CLI 作为模型默认入口。
一轮一个行为、连续会话、可选 reviewer 和最终控制器验收均不改变。

结果包含短反馈、收据及必要失败日志尾部，完整日志保留。
`.dpf/codex/<job>.platform.json` 记录操作和日志位置，监视器直接读取进展，不调用模型。
取消保留中断记录和原始输出，执行器清理自己创建的容器。
sidecar 只是显示信息，不能作为活性证明、PASS 或凭残留 RUNNING 自动重启的依据。

平台接口自身不返回轮询协议。如果客户端用会提前 yield 的外层包装它，外层仍可能发起等待调用。
离线测试证明单个工具请求返回终态，不能代替真实模型调用统计；不预先宣称省下全部 $1.711。

## 依赖解析先于构建冻结

在已经验证的同一容器和缓存执行 `cargo metadata --offline --format-version 1`，
不调用 cargo update，不失败后自动联网。准备步骤保存工作树状态和 Cargo.lock 前后原件，
只允许根 Cargo.lock 变化；其他源码变化直接停止。随后冻结包含新锁文件的完整输入。
构建期间连锁文件也不能变化，否则记录拒收、不发布、不自动重建。
依赖解析失败保留命令、输出和文件变化，不启动构建；旧 current-build 指针先失效。
缺少实际 Cargo.toml 明确失败。缓存初始化属于环境基线，不能跳过基线后把空缓存失败归因于驱动。

## 按需组件接入与首次检查

`integration` 读取当前 workspace manifest、Components.toml、选定组件入口和直接消费者中的
Rust 引用，返回目标版本、内容身份、行号和有界片段。没有找到引用不证明不存在生成或条件链接。
指导指出 Cargo 注册不等于最终链接/初始化；模型仍须验证实际调用与设备行为。
文本单列在 [component-integration.md](../../src/driver_port_factory/data/component-integration.md)。
它是当前源码导航，不是新的跨驱动共享库，不自动导入历史 PASS；原共享库的按需查询仍保留。

工作包要求首次 format/build/run 前准备当前行为已明确的初值、合法变化、必要拒绝/清理断言，
并局部检查链接、资源寿命和持锁范围。不增加 reviewer、报告或文本门禁。
后来发现具体问题仍修复并验证；这项顺序不构成代码正确性的机械证明。

## 防止串口回显误通过

`send_serial: "... echo SUCCESS"` 后接 `wait_serial: "SUCCESS"` 可能只匹配命令回显。
新增 `guest_assert`：shell 就绪后传入一个“条件成立才返回零”的命令。

```json
{"steps": [{"wait_serial": "# "}, {"guest_assert": "test 1 = 1"}]}
```

示例只演示接口，不是设备验收。执行器检查实际退出码，生成完整形式不出现在命令文本中的新标记，
避免普通回显和旧结果误匹配。完整换行边界支持 LF、CRLF、CRCRLF。
非零退出立即失败，缺少结果按原 case deadline 失败；观察写入 `guest-assertions.jsonl`。
nonce 不是对恶意 guest 的安全隔离。模型仍负责正确的行为条件；`true` 通过没有设备证明价值。
`wait_serial` 保留为低层文本观察，不能自动当作 shell 退出码或语义证据。
