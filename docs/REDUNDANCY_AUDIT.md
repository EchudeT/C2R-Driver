## 已删除或收敛

| 问题与证据 | 处理 |
| --- | --- |
| `revision_resolution` 为验证 commit 下载临时仓库，随后正式采集再次下载 | 删除独立 `revision_selection` 阶段、resolver 和 selector；第 6 步统一选择/获取/固定真实 commit，开发流程共 16 步 |

| 下载失败进入通用 AI 恢复 | Git fetch 失败保留现场暂停；恢复复用原选择、成功下载与命令证据；不重新买模型回合 |
| 文档 binding 与正式采集分别下载原件及副本 | 用已记录 HTTP 响应、CAS 和来源绑定复用一次下载，重启仍复用 |
| 官方原件强制异站点同字节副本 | 原件使用出版方 URL 和工作者来源依据；只有镜像路径仍需佐证。主机绑定不能代替真实性判断 |
| 任意错误反复交回 AI，没有成本边界 | 不变上游输入最多三次恢复请求，随后暂停，重启不清零；不是自动判定所有因果变化 |
| 同一目标报告发布为六个产物并重复传递 | 只保留 `target_study_report`；实现报告亦只保留一个 `compliance_report`，包含覆盖与自检 |
| KB 发布永远空白的 deferred 探针结果 | 删除占位；真实目标研究报告承担该语义工作 |
| 大量内部结构测试约束旧设计 | 删除旧测试，保留少量 `test_e2e_*`：单次获取/恢复、文档采集、交付到审计、裁决与恢复上限 |
